# ASTRO TRAINER — Junior Astronaut Mission Simulator

An educational React application that introduces learners to mission resource management through simplified Moon and Mars training scenarios.

## Run locally

1. Install Node.js (LTS): https://nodejs.org/
2. Extract this project folder.
3. Open a terminal inside the `astro_trainer_project` folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown in the terminal (usually http://localhost:5173).

## Deploy with StackBlitz / GitHub

- Create a new Vite + React project in StackBlitz, or upload this project to a GitHub repository.
- Keep the folder structure intact (`src`, `public`, `index.html`, `package.json`).
- For GitHub Pages, configure the Vite base path to match the repository name and use a deployment workflow. A simpler public demo can be hosted on Netlify or Vercel.

## What the simulator includes

- Moon and Mars mission selection
- Three scenario decisions per mission
- Oxygen, water, food, and energy resource indicators
- Feedback after each decision
- Training score and completion state
- Responsive layout for desktop and mobile

## NASA learning resources used for project research

- NASA Environmental Control and Life Support Systems (ECLSS): https://www.nasa.gov/reference/environmental-control-and-life-support-systems-eclss/
- NASA Crew Systems: https://www.nasa.gov/reference/crew-systems/
- NASA Humans to Mars: https://www.nasa.gov/humans-in-space/humans-to-mars/

The app's resource bars and decision effects are illustrative game mechanics, not NASA engineering data or real operational guidance. The educational concepts about air, oxygen, and water recycling are informed by the NASA resources above.
